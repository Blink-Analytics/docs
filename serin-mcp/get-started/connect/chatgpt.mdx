## Before you begin

- A Serin recruiter account (candidate accounts can connect but see no tools).
- The Serin MCP server URL: `https://mcp.serin-ai.com/mcp`.

## Connect Serin MCP to ChatGPT

Serin is listed in ChatGPT's plugin directory, so you can either search for it directly or add it manually:

- **Search for it:** in ChatGPT, open **Plugins**, search for "Serin," and select it.
- **Add it manually:** go to **Plugins → Add → Add custom MCP server** and enter `https://mcp.serin-ai.com/mcp` as the server URL.

Either way, you'll be asked how to authenticate — choose **OAuth**, then sign in with your Serin recruiter account when prompted, and pick an organization if your account belongs to more than one.

## Verify the result

- Ask ChatGPT to show your organization's profile and jobs. A working connection returns real data, not a connection error.
- If the connector doesn't appear as connected, or tool calls fail with an authentication error, remove and re-add it to force the OAuth flow to run again.
- If you're signed in as a candidate account rather than a recruiter account, the connector will connect but every recruiting tool will be unavailable to it.
