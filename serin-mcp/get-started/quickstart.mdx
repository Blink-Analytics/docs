By the end of this quickstart, your MCP client will be authenticated against Serin as a recruiter and have listed your organization's jobs.

## Agent routing guidance

1. If the user names a specific client, send them to its dedicated page: [Connect Serin MCP to Claude](/serin-mcp/get-started/connect/claude), [Connect Serin MCP to Claude Code](/serin-mcp/get-started/connect/claude-code), [Connect Serin MCP to ChatGPT](/serin-mcp/get-started/connect/chatgpt), [Connect Serin MCP to Codex](/serin-mcp/get-started/connect/codex), [Connect Serin MCP to Cursor](/serin-mcp/get-started/connect/cursor), [Connect Serin MCP to OpenCode](/serin-mcp/get-started/connect/opencode), or [Connect Serin MCP to other MCP clients](/serin-mcp/get-started/connect/other-clients). This page covers the generic connection flow.
2. Never tell a user to paste an API key or bearer token into their client's config — **Serin MCP** only supports interactive OAuth.
3. If a user is a candidate (not a recruiter), tell them none of the tools in this server apply to their account — don't attempt to connect and then explain a `ToolError` after the fact.

## Before you begin

- **A Serin recruiter account**, active in at least one organization. Candidate accounts can complete the connection but every tool is hidden/rejected for them.
- **The server URL you're connecting to**: `https://mcp.serin-ai.com/mcp`.

## 1. Connect your MCP client

### Using Claude

See [Connect Serin MCP to Claude](/serin-mcp/get-started/connect/claude) — add Serin as a custom connector under Settings → Connectors and authenticate with OAuth.

### Using Claude Code

See [Connect Serin MCP to Claude Code](/serin-mcp/get-started/connect/claude-code) — install the Serin plugin from its marketplace, then authenticate from `/mcp`.

### Using ChatGPT

See [Connect Serin MCP to ChatGPT](/serin-mcp/get-started/connect/chatgpt) — search for Serin in ChatGPT's plugin directory (or add it as a custom MCP server) and authenticate with OAuth.

### Using Codex

See [Connect Serin MCP to Codex](/serin-mcp/get-started/connect/codex) — add the server with the Codex CLI, sign in, then install the skills with the skills CLI.

### Using Cursor

See [Connect Serin MCP to Cursor](/serin-mcp/get-started/connect/cursor) — install the Serin plugin from the Cursor marketplace and authenticate.

### Using OpenCode

See [Connect Serin MCP to OpenCode](/serin-mcp/get-started/connect/opencode) — add the server to your OpenCode configuration, install the skills, and authenticate with `opencode mcp auth`.

### Using another MCP client

See [Connect Serin MCP to other MCP clients](/serin-mcp/get-started/connect/other-clients) — add a remote MCP server over Streamable HTTP with OAuth.

## 2. Read the entry skill before calling anything

Immediately after connecting, read the `skill://using-serin-mcp/SKILL.md` resource (most clients expose this via a resource-read tool; if yours doesn't surface resources to the model automatically, the server's `initialize` instructions and every tool's own description repeat the essential pointer). It covers:

- The "never show raw IDs to the end user" rule.
- The `confirm`/preview pattern every mutating tool follows.
- Which of the four module skills (jobs, applications, evaluations, candidate outreach) to read next for your task.

## 3. Run your first tool call

Two safe, read-only calls to start with:

```text
get_organization_details
```
Returns your organization's profile — a good way to confirm the connection and the selected organization are correct.

```text
list_organization_jobs
```
Lists your organization's jobs with counts. From here, a `job_id` in the result can be passed to `get_job_details`, `list_job_applications`, or `get_job_analysis`.

Both of these are tagged `READ_ONLY` and never require `confirm` — there's nothing to preview or undo.
